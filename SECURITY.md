# Política de segurança

## Escopo

Esta política se aplica ao código e à demonstração publicados neste repositório. Como o projeto é uma DEMO executada no navegador, não envie dados pessoais, credenciais, tokens ou informações confidenciais em issues, pull requests ou anexos públicos.

## Como reportar uma vulnerabilidade

Não publique detalhes de uma vulnerabilidade explorável em uma issue pública. Use a opção **Report a vulnerability** na aba **Security** do repositório, se estiver disponível, para enviar um relatório privado. Se essa opção não estiver disponível, entre em contato com o mantenedor por um canal privado associado ao perfil GitHub `guilhermeandrade1201-creator`; não inclua segredos em mensagens públicas.

Inclua, quando possível, uma descrição do impacto, os passos mínimos para reproduzir o problema em um ambiente próprio e uma sugestão de correção. Não teste vulnerabilidades contra sistemas de terceiros.

## Resposta e divulgação

O mantenedor analisará os relatos conforme disponibilidade. Não há prazo de resposta ou correção garantido. Peça autorização antes de divulgar publicamente detalhes ainda não corrigidos.

## Versões

A política cobre a versão publicada neste repositório. Este é um projeto pessoal e experimental; não há garantia de suporte ou de atualizações de segurança.
